# 证件照制作页面 AI Aurora UI 升级设计

## 背景

当前页面已完成证件照制作的基础前端流程：进入制作、上传照片、mock 生成、结果预览、下载 PNG。下一步目标是把页面从“可用 demo”升级成更像真实产品的现代化前端页面。

这次升级采用精致克制的 AI Aurora 视觉风格，但产品表达以证件照规格为核心。证件照是标准化场景，页面应优先围绕 1寸、2寸、小二寸、背景色、输出格式等信息组织，而不是堆叠泛化的 AI 能力标签。

## 目标

- 全流程视觉升级：Welcome、Upload、Processing、Result 四个状态统一成更高级的 AI 产品质感。
- 规格优先：把 1寸、2寸、小二寸作为核心选择项，背景色作为辅助配置。
- 保持流程简单：不引入路由、不接后端、不增加真实合规检测。
- 保持表达准确：只描述前端 mock 和预览能力，不承诺官方合规或真实 AI 抠图效果。

## 非目标

- 不接入后端接口。
- 不做真实人像检测、抠图、合规审核或证件照尺寸认证。
- 不引入复杂裁剪编辑器。
- 不增加登录、订单、支付、历史记录等业务模块。

## 信息架构

页面继续保持单页四状态流程：

1. Welcome：展示产品定位和规格化证件照制作入口。
2. Upload：选择规格、选择背景色、上传照片、发起生成。
3. Processing：展示规格应用、背景替换、尺寸生成的处理过程。
4. Result：展示原图与结果图，对外显示所选规格、背景色和下载操作。

## 规格选择

新增证件照规格选项，优先级高于背景色：

- 1寸：用于常见报名、资料提交场景。
- 2寸：用于常见证书、申请材料场景。
- 小二寸：用于部分考试、签证或资料场景。

每个规格在 UI 中展示名称和简短说明。mock 生成可以根据规格映射到不同 canvas 尺寸，结果页展示当前规格名称和输出格式。

## 视觉方向

采用浅色 AI Aurora 风格：

- 背景：浅色基调、柔和极光渐变、细网格纹理、局部光斑。
- 卡片：玻璃拟态、轻微发光描边、清晰层级。
- 色彩：主色为蓝紫渐变，辅助使用青色/紫色光效；白底、蓝底、红底保持真实证件照语义。
- 排版：首页更像产品发布页，上传页更像专业工具页，结果页更像交付确认页。
- 动效：保持克制，使用进入过渡、hover、扫描线、背景轻微漂浮，不做满屏粒子或强闪烁。

## 交互设计

### Welcome

- 保留主 CTA“开始制作证件照”。
- 右侧样张区改成规格化预览，展示 1寸、2寸、小二寸的卡片感。
- 文案强调“选择规格 → 上传照片 → 生成证件照”。

### Upload

- 上传页右侧配置面板调整为：先选规格，再选背景色。
- 规格选项使用卡片或 token 样式，选中态清晰。
- 背景色继续提供白、蓝、红，作为规格后的辅助配置。
- 上传成功后显示“已准备好生成”一类状态反馈。
- 未上传照片时生成按钮禁用。

### Processing

处理步骤文案调整为证件照语义：

1. 校准人像位置。
2. 应用证件照规格。
3. 替换标准背景色。
4. 生成可下载照片。

处理时间保持约 1.8 秒，不刻意拉长等待。

### Result

- 结果页展示原图和证件照效果。
- 增加结果摘要：当前规格、背景色、输出格式 PNG。
- 下载按钮文案包含规格，例如“下载 1寸证件照”。
- 重新制作保持次级操作。

## 数据与状态

在现有状态基础上增加规格状态：

- `selectedSpec`：当前规格，默认 1寸。
- `photoSpecs`：规格配置数组，包含 id、名称、说明、canvas 尺寸、下载文件名片段。

现有状态继续保留：

- `step`
- `selectedFile`
- `originalUrl`
- `resultUrl`
- `background`
- `error`

mock 生成函数根据所选规格决定 canvas 宽高，并继续根据所选背景色填充背景。

## 文件范围

主要修改：

- `src/App.tsx`：增加规格配置、规格状态、规格选择 UI、处理文案、结果摘要和下载文件名。
- `src/styles.css`：升级整体视觉系统、规格卡片、处理步骤、结果摘要和响应式样式。

保持不变：

- Vite/React/TypeScript 技术栈。
- 上传依赖 `react-dropzone`。
- 动效依赖 `framer-motion`。
- icon 依赖 `lucide-react`。

## 验证计划

- 运行 `npm run build`。
- 使用 Playwright 打开本地页面并验证：
  1. 首页能进入制作页。
  2. 可选择 1寸、2寸、小二寸规格。
  3. 可选择白、蓝、红背景色。
  4. 上传图片后生成按钮启用。
  5. 生成后结果页展示所选规格、背景色和 PNG 输出格式。
  6. 下载文件名包含规格和底色。
  7. 点击重新制作后状态清空，生成按钮恢复禁用。
  8. 控制台无错误。

## 成功标准

- 页面视觉明显更高级，风格统一且不过度炫技。
- 用户能一眼理解这是证件照规格化制作工具。
- 1寸、2寸、小二寸成为主配置项。
- 主流程仍然简单、稳定、可完整跑通。
